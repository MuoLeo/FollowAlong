# 오류 판별 구현 및 평가 상태

기준: 2026-11-05. V50 완료 감지와 후속 오류 판별 실험을 구분한다.

## 데모에 사용하는 기능

V50의 기존 HTTP 서비스와 정책은 그대로 유지한다.
- 목표 단계 + 0.5초 간격 프레임 입력 → 완료 후보.
- 최근5프레임, 3회 연속 양성, Stage5 탑승 조건.
- 완료 후보 후 수동/외부 검사 결과를 받고 Backend가 단계 전환을 승인한다.
- `error_verifier_available=false`, `assembly_error_checked=false`는 실제 자동 검증이 연결되기 전까지 유지한다.
- `valid/invalid/uncertain` 상태 관리가 존재해도 그 값을 자동 예측하는 모델이 완성됐다는 뜻은 아니다.
- 모듈의42개 테스트와 저장 영상 재생은 실제 카메라/팀 Backend/Frontend 통합 성능을 대신하지 않는다.

## V56: 정상 자료 보강

전체 화면의 frozen SupCon embedding + stage one-hot → StandardScaler → LogisticRegression(C=0.1).
영상 단위 교차검증, 임계값0.5. 정상120장, 오류15장, 총135장.

| 지표 | 결과 |
|---|---:|
| 전체 분류 정확도 | 94.81% |
| 오류 검출률 | 93.33% (14/15) |
| 오류 정밀도 | 70.00% (14/20) |
| 정상 오탐 | 6/120 |
| 혼동행렬: 행=정상/오류, 열=정상/오류 | [[114,6],[1,14]] |

Stage3 정상 오탐은 showcase73.11/76.56/80.01초, rec05 92/92.5/93초.
Stage5 오류 누락은 error_stage_unkown_01.mp4 121.1348초.
94.81%는 제한된 자료의 분류기 교차검증이며 실시간 정확도가 아니다.
encoder 자체는 과거 rec01~04로 학습되어 전체 파이프라인 독립 평가도 아니다.

## V58: Stage3 짝 영상 추가

새 정상→노란 블록 누락→정상 영상2개에서18장 추가. 총153장.
촬영 조건이 유사한 새 영상2개를 동일 capture group으로 묶어 함께 제외한다.

| 항목 | V56 | V58 |
|---|---:|---:|
| 동일 기존135장 정상 오탐 | 6/120 | 6/120 |
| 동일 기존135장 오류 누락 | 1/15 | 2/15 |
| 동일 기존 Stage3 정상 오탐 | 6/24 | 3/24 |

새 두 영상 전체를 제외한 검사에서는 정상12장 모두 정상, 오류6장 모두 미검출.
이는 기존 자료로만 학습한 V56 방식의 새 촬영 대응 한계를 보여준다.
V58 전체 그룹교차검증은 [[126,6],[8,13]], 정확도90.85%, 오류검출률61.90%.
자료 구성이 달라 전체 정확도만 V56과 직접 비교하지 않는다. V58을 서비스에 채택하지 않는다.

## V59: 특정 부품 확인 진단

전체 화면의 embedding 대신 수동 지정 레고 ROI의 픽셀을 사용한다.
- Stage3: 고정 HSV 정의와 학습 그룹에서 정한 임계값으로 노란 블록의 존재/부재 확인.
- Stage5: 확대 ROI의 공간별 윤곽+RGB 특징으로 고무 타이어 누락 분류.
- 모든 새 Stage3/Stage5 pair 영상은 같은 촬영 그룹으로 묶어 평가한다.
- 범위에 맞지 않는 뒤집힌 부품/완전히 잘못 만든 자동차 등은 제외한다. 정상으로 재라벨링하지 않는다.

| 특정 과제 | 전체 그룹교차검증 | 새 촬영 그룹 전체 제외 결과 |
|---|---|---|
| 노란 블록 존재/부재 | 정상36/36, 누락8/8 구분 | 정상12/12, 누락6/6 구분 |
| 고무 타이어 누락 | 정상35/36, 누락0/9 검출 | 정상12/12, 누락0/6 검출 |

노란 블록이 잘못된 위치에 있거나 ROI 안에 떨어져 있어도 색 기반 존재 판정을 통과할 수 있다.
따라서 노란 블록 존재를 전체 조립 정상 판정이나 Stage3 일반 오류 정확도100%라고 표현하지 않는다.
오류를 포함하는 촬영 그룹은 과제마다2개뿐이고, 인접 프레임은 독립 표본이 아니다.
타이어 분류는 이번 방식에서도 실패했으며 채택하지 않는다.

## 현재 미완성인 부분

자동 레고/부품 위치 추적, 손가림 등 입력 품질 판정, 타이어/휠 직접 검사,
모든 단계의 일반 오조립 판별 및 실시간 서버 연결은 미완성이다.
Stage2 오류 성능은 자료가 없어 평가하지 못했다.
rec06은 이번 실험 학습에 사용하지 않았다. 과거 완료 감지 평가에서 이미 확인된 자료이며,
정상 rec06만으로 일반 오류 검출 성능을 검증할 수는 없다.

## 통합 원칙

금요일 최소 데모는 V50 완료 후보 감지 → 명시적인 수동 확인 → Backend 승인 → 다음 단계 안내로 구성한다.
수동 검사 결과는 AI 정상/오류 판정으로 표시하지 않는다.
후속 실험은 독립 폴더에 보존하고, 기존 V50 가중치/임계값/서버 정책은 변경하지 않는다.
